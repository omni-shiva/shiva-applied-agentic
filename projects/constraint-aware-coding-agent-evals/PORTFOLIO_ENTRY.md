# Portfolio entry

## Project title

Constraint-Aware Coding Agent Evaluation Lab

## One-line description

Built an independent synthetic evaluation lab for coding agents that separates functional correctness from runtime constraint compliance through isolated adversarial probes and reproducible evidence.

## Skills demonstrated

- Python package and command-line interface design
- Evaluation harness engineering
- Observable constraint and adversarial probe design
- Temporary-workspace file separation
- Structured JSON and Markdown reporting
- Reproducibility with SHA-256 manifests
- Continuous integration across Python versions
- Privacy-aware public artifact construction

## Verified demonstration result

Both fictional candidates pass the ordinary functional tests. The reference passes all six focused behavior probes, while the intentionally flawed comparison passes two. This exposes four implementation-behavior violations that correctness-only grading misses.
