# Contributing

Contributions that improve deterministic evaluation, error reporting, documentation, or additional fully synthetic examples are welcome.

## Requirements

1. Use only public or newly authored synthetic material.
2. Keep functional tests separate from focused behavior probes.
3. Give every new constraint an accepted fixture and a single-fault adversarial fixture.
4. Avoid network or paid-service requirements in the default test path.
5. Verify that every adversarial fixture fails only its paired probe.
6. Run the full unit-test suite and public-release scan.
7. Update the manifest after the final intentional change.

Do not submit proprietary code, private prompts, confidential traces, credentials, personal information, or artifacts copied from a restricted engagement.
